Токено-эффективные инструменты (Bash-команды)Обычные команды вроде cat или grep -r «съедают» контекстное окно огромным количеством лишнего текста. Вот список максимально сжатых и информативных команд:1. Быстрая разведка структуры (вместо тяжелого tree)Команда: find . -maxdepth 3 -not -path '*/.*' -not -path '*node_modules*'Зачем: Показывает структуру каталогов верхнего уровня. Никакой графической «мишуры» (веточек tree), только чистые пути. Спасает от чтения тысяч файлов.2. Поиск зависимостей и импортов (Точечный grep)Команда: grep -rnw --exclude-dir={node_modules,.git,dist} "имя_функции_или_класса" .Зачем: Флаг -w ищет точное совпадение слова, а --exclude-dir отсекает мусор. Агент сразу видит файлы и номера строк, где используется компонент, не читая сами файлы целиком.3. Сверх-эффективный просмотр сигнатур (Без чтения тела функций)Команда: sed -n '1,50p' путь/к/файлу.py (или через head -n 50)Зачем: Позволяет прочитать только импорты и первые строки файла, чтобы понять интерфейс класса/модуля, не загружая в контекст сотни строк реализации.4. Проверка сигнатур в динамических языках (для JS/TS/Python)Команда (Python): python3 -c "import ast; print([node.name for node in ast.parse(open('file.py').read()).body if isinstance(node, ast.FunctionDef)])"Зачем: Возвращает только список названий функций в файле в одну строку. Идеально для экономии токенов.5. Анализ Git для понимания контекста (Кто и зачем менял этот код)Команда: git log -n 3 --oneline -- путь/к/файлу.jsЗачем: Буквально 3 строчки текста, но агент сразу понимает недавний контекст задачи и бизнес-логику этой фичи.Команда 2: git blame -L 10,20 путь/к/файлу.js (только для целевого участка). Помогает понять, менялся ли этот кусок кода в рамках связанных задач.6. Быстрый запуск и фильтрация тестовКоманда: pytest -q или npm test -- --silentЗачем: Флаги -q (quiet) и --silent подавляют лишний вывод (логгирование, успешные тесты) и выводят в консоль только ошибки, если они есть. Если всё успешно — агент получает 0 токенов ответа, что идеально.
