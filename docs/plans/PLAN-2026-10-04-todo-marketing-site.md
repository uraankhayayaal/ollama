# PLAN-2026-10-04-todo-marketing-site

Маркетинговый сайт проекта: мультиязычность (основной — русский), метрики токенов/моделей, CTA на SaaS-версию.

---

## Этап 1: Дизайн-система и визуальная концепция

- [ ] 1.1. Определить визуальный стиль: тёмная тема, акцентные цвета, типографика (премиум-уровень)
- [ ] 1.2. Создать дизайн-систему: цветовая палитра, шрифты, сетки, компоненты UI
- [ ] 1.3. Разработать логотип и фавикон
- [ ] 1.4. Создать анимации и микровзаимодействия (scroll-reveal, hover-эффекты)
- [ ] 1.5. Подготовить иллюстрации/3D-графики для ключевых секций
- [ ] 1.6. Обеспечить адаптивность: mobile-first, брейкпоинты для всех устройств
- [ ] 1.7. Оптимизировать Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms

## Этап 2: Структура и контент (мультиязычность)

- [ ] 2.1. Спроектировать структуру сайта: Home, Features, Pricing, Docs, Blog, About
- [ ] 2.2. Реализовать i18n-фреймворк (основной язык — русский, дополнительно — английский)
- [ ] 2.3. Создать систему переводов: JSON/YAML-файлы с ключами
- [ ] 2.4. Реализовать переключатель языка с сохранением выбора (cookie/localStorage)
- [ ] 2.5. Написать контент для главной страницы (RU): герой-секция, преимущества, CTA
- [ ] 2.6. Написать контент для страницы возможностей (RU): детальное описание фич
- [ ] 2.7. Написать контент для страницы цен (RU): тарифные планы
- [ ] 2.8. Перевести весь контент на английский
- [ ] 2.9. Реализовать hreflang-теги для SEO
- [ ] 2.10. Добавить RTL-поддержку (если потребуется для других языков)

## Этап 3: Ключевые секции и UX

- [ ] 3.1. Герой-секция: мощный заголовок, подзаголовок, CTA-кнопка «Попробовать бесплатно»
- [ ] 3.2. Секция «Как это работает»: 3-4 шага с анимацией
- [ ] 3.3. Секция «Возможности»: карточки с иконками и описаниями
- [ ] 3.4. Секция «Метрики»: интерактивные счётчики токенов и моделей
- [ ] 3.5. Секция «Сравнение»: таблица с конкурентами (Claude Code, Cursor, etc.)
- [ ] 3.6. Секция «Отзывы»: карусель с цитатами пользователей
- [ ] 3.7. Секция «FAQ»: аккордеон с частыми вопросами
- [ ] 3.8. Финальная CTA-секция: призыв к действию с кнопкой «Начать бесплатно»
- [ ] 3.9. Реализовать плавный скролл и навигацию по секциям
- [ ] 3.10. Добавить прогресс-бар чтения страницы

## Этап 4: Метрики токенов и моделей

- [ ] 4.1. Определить источники данных для метрик (API SaaS-версии, публичная статистика)
- [ ] 4.2. Реализовать API-эндпоинт для получения агрегированных метрик
- [ ] 4.3. Создать компонент «Живые метрики»: анимированные счётчики
- [ ] 4.4. Отображать: общее количество токенов, количество моделей, количество пользователей
- [ ] 4.5. Реализовать автообновление метрик (polling или WebSocket)
- [ ] 4.6. Добавить график использования токенов по времени (Chart.js/D3.js)
- [ ] 4.7. Реализовать fallback-данные, если API недоступен

## Этап 5: Интеграция с SaaS-версией

- [ ] 5.1. Реализовать кнопку «Попробовать бесплатно» → редирект на SaaS-версию
- [ ] 5.2. Реализовать OAuth-авторизацию через GitHub/GitLab на сайте
- [ ] 5.3. Добавить форму регистрации с валидацией
- [ ] 5.4. Реализовать страницу «Вход» с перенаправлением в SaaS
- [ ] 5.5. Добавить deep-linking: переход сразу к созданию проекта после входа
- [ ] 5.6. Реализовать демо-режим: попробовать без регистрации (если возможно)

## Этап 6: SEO и производительность

- [ ] 6.1. Реализовать мета-теги: title, description, Open Graph, Twitter Cards
- [ ] 6.2. Создать sitemap.xml и robots.txt
- [ ] 6.3. Реализовать структурированные данные (Schema.org)
- [ ] 6.4. Оптимизировать изображения: WebP, lazy loading, srcset
- [ ] 6.5. Реализовать code splitting и lazy loading компонентов
- [ ] 6.6. Настроить кэширование: Service Worker, CDN
- [ ] 6.7. Добавить Google Analytics / Яндекс.Метрика
- [ ] 6.8. Реализовать A/B-тестирование ключевых элементов

## Этап 7: Техническая реализация

- [ ] 7.1. Выбрать стек: Next.js / Astro / Gatsby (SSR/SSG для SEO)
- [ ] 7.2. Настроить сборку и деплой (Vercel / Netlify / Cloudflare Pages)
- [ ] 7.3. Реализовать CI/CD: автоматический деплой при пуше в main
- [ ] 7.4. Настроить мониторинг и алертинг (UptimeRobot, Sentry)
- [ ] 7.5. Реализовать форму обратной связи
- [ ] 7.6. Добавить чат-бот для быстрой помощи (опционально)
