# CLI-команды

Все команды — `go run . <команда>`. Первая позиция после точки выбирает
агента или режим; проект всегда живёт в `temp/<имя_проекта>`.

## Карта команд

| Команда | Что делает | Аргументы |
|---|---|---|
| `serve` | Web UI + чат + доска на много проектов | `[адрес]` |
| `plan` | Планировщик: декомпозиция и исполнение по волнам | `<проект> <промпт> [--resume]` |
| `kanban` | Оркестрация на доске: архитектор → лиды → специалисты | `<проект> <промпт>` |
| `backend` | Standalone backend-разработчик | `<проект> [промпт]` |
| `frontend` | Standalone frontend-разработчик | `<проект> [промпт]` |
| `devops` | Standalone DevOps | `<проект> <промпт>` |
| `backendlead` | Декомпозиция бэкенда | `<проект> <промпт>` |
| `frontendlead` | Декомпозиция фронтенда | `<проект> <промпт>` |
| `devopslead` | Декомпозиция инфраструктуры | `<проект> <промпт>` |
| `qalead` | Тест-план и декомпозиция QA | `<проект> <промпт>` |
| `qa` | QA-инженер: сборка → тесты → приёмка | `<проект> <промпт>` |
| `accept` | Детерминированная приёмка без LLM | `<проект>` |
| `index` | Индексация проекта в Qdrant | `<проект>` |
| `review` | Ревью Merge Request | `<URL>` |
| `listen` | Слушатель новых MR (только GitLab) | — |

> `generate` — **алиас** `backend`, оставлен для обратной совместимости
> (`main.go:141-143`).

## Служебные команды

### `serve`

```bash
go run . serve
go run . serve 0.0.0.0:8090
```

Позиционный аргумент **переопределяет** `AI_WEB_ADDR` (`main.go:88-94`).
Пароль берётся из `AI_WEB_PASSWORD`; при пустом значении вход без пароля.

Имя лог-файла процесса — `logs/server.log`; логи проектов —
`logs/<проект>.log` (`main.go:396-401`).

### `accept`

```bash
go run . accept <проект>
```

Определяет стек, собирает, запускает, проверяет логи, LSP и анализатор.
Код выхода: `0` при успехе, `1` при `reject`.

Подробнее — [Приёмка](../20-features/acceptor.md).

### `index`

```bash
go run . index <проект>
```

Обходит `temp/<проект>`, режет на чанки, грузит в Qdrant. Печатает
ветку и коммит (`main.go:455`).

```
index: ветка ai/task/42, коммит a1b2c3d
Индексация "billing" завершена: файлов 128, чанков 640, размерность 768, ветка ai/task/42, коллекция project_code_base
```

Коллекция создаётся при первом запуске (create-if-not-exists). Пустой
коммит печатается как `-` — проект без Git.

### `review`

```bash
go run . review https://gitlab.com/group/project/-/merge_requests/42
```

Таймаут цикла — `REVIEW_TIMEOUT` (дефолт 10 минут), `main.go:114`.

Для провайдера `trim` дифф передаётся **целиком**, без разбиения на части
(`main.go:127-132`).

### `listen`

```bash
GITLAB_URL=https://gitlab.com \
GITLAB_TOKEN=... \
GITLAB_PROJECTS=123,456 \
DB_FILENAME=discovered_mrs.txt \
POLL_INTERVAL=30s \
go run . listen
```

Только GitLab. Повторно известные MR не ревьюятся (база в файле).

## Агентские команды

```bash
go run . backend  <проект> "Напиши микросервис хранения файлов"
go run . frontend <проект> "Веб-интерфейс для просмотра файлов"
go run . devops    <проект> "Docker Compose с моками + манифесты Kubernetes"
go run . qa        <проект> "Проверь API-контракты и напиши автотесты"
```

Лиды декомпозируют задачу на шаги:

```bash
go run . backendlead  <проект> "Декомпозируй сервисную часть, спроектируй контракты API"
go run . frontendlead <проект> "Декомпозируй интерфейс на UI-модули, спроектируй стейт"
go run . devopslead   <проект> "Декомпозируй инфраструктуру: Compose локально, K8s на проде, CI/CD"
go run . qalead       <проект> "Сформируй тест-план по контрактам архитектора"
```

> Для `backend`/`frontend` промпт необязателен — подставится
> `defaultPrompt`. Для остальных промпт обязателен.

## `plan`

```bash
go run . plan <проект> "Создай микросервис хранения файлов и ревью кода"
go run . plan <проект> --resume
```

С планировщиком: декомпозиция → волны → исполнение → цикл приёмки.
`--resume` (или `PLAN_RESUME=1`) восстанавливает план из чекпоинта
**без повторного вызова модели** — экономит токены.

Чекпоинты требуют Redis: включаются при явном `REDIS_ADDR`,
`PLAN_CHECKPOINT=1` или `--resume` (`main.go:683-684`).

## `kanban`

```bash
go run . kanban <проект> "Спроектируй и собери сервис: архитектура, контракты, DevOps, тесты"
```

Полный цикл на доске. В консольном режиме архитектору выдаётся **только
RAG** (`main.go:243-250`) — `AskUser` и `IndexBackground` доступны лишь в
Web UI-сессии. Это осознанная деградация: в консоли нет UI для вопросов.

## Общий таймаут

Весь цикл агента ограничен `REVIEW_TIMEOUT` (по умолчанию 10 минут)
(`main.go:111-116`). Дефолт заведомо выше таймаута одного HTTP-запроса
провайдера (5 минут), чтобы один долгий ответ модели не съедал весь бюджет.

```bash
REVIEW_TIMEOUT=30m go run . plan <проект> "..."
```
