# Сжатие контекста

Контекст модели — конечный ресурс. Длинный агентский цикл (десятки раундов
инструментов) раздувает историю, и без управления ею запрос падает с
`400 exceeded_context_size`.

Реализовано шесть фаз (Ф-6…Ф-11) плюс скелетон-кеш.

## Настройка

```bash
# Базовое сжатие
CODEGEN_HISTORY_BUDGET=0       # лимит символов истории; 0 = только по окну модели
CODEGEN_HISTORY_TOKENS=0       # лимит токенов по фактическому usage (Ф-11)

# Фазы (все выключены по умолчанию)
CODEGEN_HISTORY_NOTICE=0       # Ф-6  памятка модели о сжатии
CODEGEN_HISTORY_EVICT=0        # Ф-7  вытеснение в RAG-эпизоды
CODEGEN_HISTORY_RANK=0         # Ф-8  семантический выбор кандидатов
CODEGEN_HISTORY_OUTLINE=0      # Ф-9  LSP-оглавления убранных файлов
CODEGEN_HISTORY_COMPACT=0      # Ф-10 компакция середины моделью

# Смежное
CODEGEN_SKELETON_CACHE=1       # кеш сигнатур (вкл по умолчанию)
CODEGEN_READ_MAX_FILE=100000   # лимит символов на файл при чтении
CODEGEN_READ_MAX_TOTAL=800000  # лимит символов за вызов ReadFiles
```

> `CODEGEN_SKELETON_CACHE` **не описан в `.env.example`**, но активен по
> умолчанию (`tools/skeleton.go:43-50`). Выключается `0`/`false`/`off`.

**Все флаги `CODEGEN_HISTORY_*`, кроме бюджетов, выключены по умолчанию.**
Базовая страховка по окну модели работает всегда и не требует настройки.

## Базовый алгоритм

`runner/compress.go`. История ужимается под символьный бюджет
`CODEGEN_HISTORY_BUDGET`, сохраняя:

- **Начало** — системный промпт и постановка задачи (всегда).
- **Хвост** — последние реплики диалога (всегда).
- **Середина** — выборочно.

**Разрыв внутри tool-сообщений запрещён** — юниты неделимы, иначе модель
получит «начало» вызова без «конца» и зациклится.

## Страховка по окну модели

Даже при `CODEGEN_HISTORY_BUDGET=0` история удерживается в пределах окна
провайдера.

`runner.ModelLimits{InputTokens, OutputTokens, ThinkTokens}`
(`runner/runner.go:90-103`): `0` = провайдер не сообщает лимит, тогда сжатие
идёт только по явным настройкам.

Интерфейс `ModelLimitsProvider` — опциональное расширение `ChatProvider`.
Реализуют: Ollama (`models/OllamaModel.go:57-63`), YandexGPT
(`models/AlisaDefinition.go:62`), Trim (`models/TrimProvider.go:106`),
Layered — проксирует к нижнему (`models/layered.go:114-123`).

Цикл:

```
lastInputTokens (факт прошлого запроса)
      │
      ▼
compressHistoryForRound(...)  — перед каждым раундом
      │
      ▼
обновление фактического входа
```

> **Это и есть Ф-11:** бюджет считается по фактическому входу предыдущего
> запроса, а не по эвристике с нуля. Поэтому разросшаяся история не роняет
> цикл, даже если все флаги выключены.

## Оценка токенов

Без токенизатора: максимум из `len/4` и `число_слов × 1.25`
(`runner/runner.go:111-119`). Кириллица учитывается — иначе оценка была бы
занижена в разы.

## Фазы

| Фаза | Флаг | Что делает |
|---|---|---|
| Ф-6 Уведомление | `CODEGEN_HISTORY_NOTICE` | Явные метки о том, что часть истории сжата. Чтобы модель не считала отсутствие сообщений ошибкой |
| Ф-7 Вытеснение | `CODEGEN_HISTORY_EVICT` | Выброшенные раунды пишутся в RAG как **эпизоды диалога** и потом могут быть найдены через `CodeSearch` |
| Ф-8 Ранжирование | `CODEGEN_HISTORY_RANK` | Отбор кандидатов на сохранение по cosine-близости к текущему состоянию |
| Ф-9 Оглавления | `CODEGEN_HISTORY_OUTLINE` | Вместо удалённого кода — LSP-`documentSymbol` убранных файлов |
| Ф-10 Компакция | `CODEGEN_HISTORY_COMPACT` | Один вызов провайдера на абстрактивное сжатие середины |
| Ф-11 Бюджет по usage | `CODEGEN_HISTORY_TOKENS` | Бюджет от фактического входа, а не от эвристики |

## Скелетон-кеш

`tools/skeleton.go` — кеш сигнатур функций и типов **без тел**, по ключу
`path|size|mtime`. Кап 512 записей, очистка при переполнении.

Экономит чтение больших файлов: чтобы понять структуру, достаточно
сигнатур. Включён по умолчанию.

## Подключение

`runctx.WithCompression(ctx, project, dir, ragc)` — единая точка сборки
сервисов сжатия. Подключается в трёх местах: CLI, планировщик, сервер
(`runctx/runctx.go:25-48`).

Сами флаги читаются в цикле раннера, не здесь.

## Адаптеры

| Свойство | Реализация |
|---|---|
| `cc.Notice` | `runner/compression.go` |
| `cc.Evict` | `ragc.EvictionEpisodes(ctx, p, "dialog", ...)` (`rag/episodes.go`) |
| `cc.Rank` | `ragc.Similarity` (cosine) |
| `cc.Outline` | `lspclient.Shared().Outliner` + `tools.OutlineFromOutliner`; ошибка не fatal |
| `cc.Compact` | Один вызов провайдера |

## Рекомендуемая конфигурация

### Минимум (работает из коробки)

```bash
# Ничего настраивать не нужно — страховка по окну модели всегда активна
```

### Длинные сессии

```bash
CODEGEN_HISTORY_BUDGET=200000
CODEGEN_HISTORY_NOTICE=1
CODEGEN_HISTORY_EVICT=1        # требует Qdrant
CODEGEN_HISTORY_OUTLINE=1      # требует LSP
```

### Максимум качества

```bash
CODEGEN_HISTORY_TOKENS=100000
CODEGEN_HISTORY_RANK=1         # требует Qdrant
CODEGEN_HISTORY_COMPACT=1      # +1 вызов провайдера на цикл сжатия
```

Ф-7, Ф-8 требуют работающего Qdrant; Ф-9 — работающего LSP. Без них
соответствующие адаптеры молча отключаются.

## Проверить, что сжатие работает

```bash
LLM_DEBUG=1 go run . plan <проект> "..."
```

В логе видны раунды и, при срабатывании сжатия, его признаки.
